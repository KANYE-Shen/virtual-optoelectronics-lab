# 基于 Unity 的虚拟光电实验平台

一个基于 Unity 引擎开发的虚拟光电实验系统，用于模拟光电实验过程、设备交互及实验现象展示，支持教学演示与虚拟仿真实验。

---

## 一、项目简介

本项目致力于构建一个“可以在电脑里做实验”的虚拟光电实验室。

传统光电实验往往存在以下问题：

- 实验设备昂贵，资源有限
- 操作复杂，新手上手困难
- 实验过程难以重复观察
- 某些现象难以直观展示

本项目通过 Unity 3D 技术，将实验设备、操作流程与实验现象进行数字化重建，使用户可以：

👉 在虚拟环境中完成完整实验流程  
👉 观察关键物理现象变化  
👉 进行交互式操作与参数调节  

---

## 二、项目目标

- 构建高仿真的光电实验虚拟环境
- 实现实验设备的交互式操作
- 可视化关键实验数据与物理过程
- 支持教学演示与自主学习
- 为后续扩展（如更多实验模块）提供基础架构

---

## 三、核心功能

### 1. 虚拟实验环境

- 3D 场景还原实验室结构
- 实验设备（光学元件、控制模块等）建模
- 支持视角切换与场景漫游

---

### 2. 交互式实验操作

- 鼠标点击 / 拖拽控制实验设备
- 模拟真实实验步骤流程
- 支持开关、旋钮、滑动控制等操作逻辑

---

### 3. 实验流程模拟

- 按实验步骤逐步引导
- 状态驱动（Step-based）实验逻辑控制
- 不同步骤之间具有严格依赖关系

---

### 4. 数据与现象可视化

- 实验结果实时更新
- 曲线图展示（如强度变化、参数变化等）
- 支持数据与界面联动

---

### 5. 可扩展架构

- 模块化设计，便于增加新实验
- 支持接入外部计算（如 Python）
- 可扩展为 WebGL / 桌面应用
